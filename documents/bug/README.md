# BUG 文档目录

本目录存放 LudoBurrow 开发与发布过程中重要缺陷的修复文档。**目录暂无 BUG 文档**——首个缺陷立档后本说明保留不变。

## 命名格式

`BUG<YYYYMMDDHH24MISS>-<中文简述>.md`

- `BUG`：固定前缀，全大写
- `YYYYMMDDHH24MISS`：14 位时间戳（年月日时分秒，24 小时制）
- `-`：英文短横线分隔符
- `<中文简述>`：一句话概括 BUG 主题（中文，不含特殊字符）
- `.md`：Markdown 扩展名

## 示例

`BUG20260920143025-拼图三区校验未触发结算.md`

## 文档结构（建议）

每个 BUG 文档包含：现象（复现步骤）→ 根因（定位过程）→ 修复方案 → 回归验证（测试用例/命令输出）→ 影响版本。

## 适用范围

- 所有写入 `documents/bug/` 的 BUG 修复文档
- 用于版本可追溯：在已有发布基础上，看每次修复的 BUG 内容
- 同一 BUG 多次修复（如回归）时，使用新的时间戳，不复用旧文件名
- 与 `documents/design/LudoBurrow 问题汇总明细.md` 的分工：本目录存单次缺陷完整文档；问题汇总存可复用经验结论
