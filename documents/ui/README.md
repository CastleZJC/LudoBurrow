# UI 原型目录

本目录预留给 LudoBurrow 的 UI 原型文件（单文件 HTML 原型，平台级页面的视觉与交互基准）。**目录随文档体系建立（2026-09-05），暂无原型文件**——按用户决策，UI 原型暂不涉及，待后续需要时在此创建。

## 命名格式（预留）

`LudoBurrow-<页面或主题>.html`

示例：`LudoBurrow-main-menu.html` / `LudoBurrow-jigsaw-board.html`

## 使用约定（预留）

- 每个平台级页面（主菜单/关卡选择/暂停/结算/设置/图片管理）可做单文件 HTML 原型
- 实现页面须与原型对齐（如老项目 Platform-MCP 的 portal 原型模式）
- UI 样式规范文档（颜色/字号/组件视觉）待原型启动后在 `documents/design/` 下补建
