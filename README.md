# LudoBurrow

> ludo（拉丁语「玩」）+ burrow（洞穴、庇护所）—— PC 端益智游戏平台

免安装、本地优先的纯前端益智游戏平台：双击 `index.html` 即玩，也可在线部署。内置三个游戏（各 50 关）：

- ⌨️ **键盘按键** — 随机字母数字 / 英文单词 / 中文拼音
- 🧩 **拼图** — 类线下拼图体验，智能切块（可选 AI 增强）
- 🌀 **迷宫** — 像素小人主题迷宫

## 技术栈

Vite · TypeScript · Vue 3 · Pinia · Canvas 2D · Vitest
